What is real and what is assumed

Designed and checked here

  • All 21 screens render at 1280 × 800 with no clipped or overflowing elements (automated check).
  • Palette contrast measured, not estimated. See the design system. Use the Ford / Cockpit switch at the top right of any page.
  • The data layer behind the Drive screen is built and tested in Kotlin (26 tests) against an ELM327 emulator.

Still unknown until the unit is read

  • Which Canbox dialect the unit speaks, so every Car-screen field is provisional.
  • Whether the vendor radio, DSP and camera services can be controlled from a third-party app.
  • The Ford logo is a trademark: this site is for your own car only, so keep it off public hosting as it stands.
  • Real frame times on the unit's GPU. The 10 ms target is verified by measurement, not by this mock-up.
